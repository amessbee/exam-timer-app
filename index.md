# Exam Timer App

A full-featured countdown timer for exam halls, built with React.

**Live demo:** [amessbee.github.io/timer](https://amessbee.github.io/timer/)

## Features

- **Preset durations** — one-click presets for 15, 30, 60, 90, 100, 120, 150, or 180 minutes
- **Custom time** — double-click the display and type any time in HH:MM:SS
- **Start / Pause / Stop / Reset** — full playback controls
- **Add 5 minutes** — "+" button in the corner for last-minute extensions
- **Editable title** — double-click the title to rename it (e.g., "CS101 Midterm")
- **Light/dark theme** — toggle with the sun/moon icon
- **Animation controls** — adjustable background animation intensity, or disable it entirely
- **Full-screen mode** — expand to fill the display for projection
- **Hide timer** — eye icon to blank the display without stopping the clock
- **State persistence** — timer survives a page refresh or accidental tab close

## Running locally

```bash
git clone https://github.com/amessbee/timer.git
cd timer
npm install
npm start
# Opens at http://localhost:3000
```
